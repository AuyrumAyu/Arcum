# Arcanum — магический мод для Minecraft 1.20.1 (Fabric)

Мана, посохи и заклинания, арканная броня, магическая еда, руда, свой Creative-таб и внутриигровой гайд (Гримуар).

## Что внутри
- **Мана**: полоска над бронёй, регенерируется сама, хранится в мире. Броня даёт макс. ману и реген.
- **Посохи** (ПКМ, тратят ману): Жезл пламени, Посох грозовика, Посох стужи, Посох жизни, Посох мерцания, Скипетр разрушения.
- **Еда**: Арканное яблоко, Печенье звёздного света, Лунный пирог (восстанавливают ману).
- **Броня**: Арканный комплект (+25 макс. маны за деталь, бонус за полный сет).
- **Блоки**: руда и глубинная руда кристаллов маны, блок кристаллов, арканные кирпичи, фонарь, Источник маны.
- **Гримуар**: книга (книга + кристалл маны), в ней все блоки и предметы с рецептами.

## Сборка через GitHub
1. Создай репозиторий на GitHub и залей всё содержимое этой папки (включая `.github`).
2. Открой вкладку **Actions** -> workflow **build** -> дождись зелёной галочки.
3. Внизу страницы запуска, в **Artifacts**, скачай `arcanum-mod` — внутри jar.

## Сборка на ПК
Нужны JDK 17 и Gradle 8.5: `gradle build`, jar появится в `build/libs/`.

## Установка
Fabric Loader 0.15+, Fabric API 0.92.2 для 1.20.1, положи jar в `mods`.
